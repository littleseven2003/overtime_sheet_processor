# 更新日志

## v1.0.0 - 2026-06-04

### 新增

- 添加 Excel 文件选择功能（点击选择 + 拖拽）
- 添加研究室自动识别和多选功能
- 添加加班数据处理和格式化输出
- 添加单元格合并功能（序号、奖惩项点、开发室）
- 添加处理日志实时显示
- 添加海蓝配色方案界面
- 添加应用 Logo
- 支持跨平台打包（Windows / macOS / Linux）

### 技术变更

- 使用 Tauri 2 框架（Rust 后端 + Vue 3 前端）
- 使用 calamine 读取 Excel 文件
- 使用 rust_xlsxwriter 写入格式化 Excel
- 使用海蓝 CSS 变量统一管理配色
- 支持 x86_64 和 ARM64 架构
