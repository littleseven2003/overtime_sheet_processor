# 发布说明

## 版本

v1.0.0

## 发布时间

2026-06-04

## 本次发布内容

### 主要功能

- 支持选择 Excel 加班数据源文件（.xlsx / .xls）
- 支持自动识别研究室列表
- 支持多选研究室进行数据提取
- 支持生成格式化 Excel 结果文件
- 支持单元格合并（序号、奖惩项点、开发室列）
- 支持文件拖拽选择
- 支持处理日志实时显示

### 技术特性

- 跨平台支持：Windows、macOS、Linux
- 支持 x86_64 和 ARM64 架构
- 本地数据处理，无需联网
- 海蓝配色界面设计

### 使用说明

1. 下载对应平台的安装包
2. 安装并启动应用
3. 点击"选择 Excel 文件"或拖拽文件到窗口
4. 选择需要提取的研究室
5. 点击"开始处理"
6. 选择保存位置，等待处理完成

### 系统要求

- Windows: Windows 10 及以上
- macOS: macOS 10.15 及以上
- Linux: 支持 WebKit2GTK 的发行版
